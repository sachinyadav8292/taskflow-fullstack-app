# TaskFlow - Full-Stack Integration Guide (Week 4)

## Integration Overview
In Week 4, the front-end (`frontend/`) was connected to the Node.js/Express REST API (`backend/`) using asynchronous `fetch()` requests (`GET`, `POST`, `PUT`, `DELETE`). Express static middleware serves both the UI and APIs from a single server.

## Local Setup & Execution Instructions
1. Open terminal and go to the `backend` folder:
   ```bash
   cd backend
   ```
2. Install required dependencies:
   ```bash
   npm install
   ```
3. Start the integrated full-stack server:
   ```bash
   npm start
   ```
4. Open your browser and visit:
   `http://localhost:5000/index.html`
